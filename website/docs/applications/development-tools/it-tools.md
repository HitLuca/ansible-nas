Homepage: [https://it-tools.tech/](https://it-tools.tech/)

Handy online tools for developers: converters, generators, encoders/decoders and more, all in one static web app.

## Usage

Set `it_tools_enabled: true` in your `inventories/<your_inventory>/group_vars/nas.yml` file.

IT-Tools' web interface can be found at [http://ansible_nas_host_or_ip:8114](http://ansible_nas_host_or_ip:8114)
